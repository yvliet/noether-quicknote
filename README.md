# Quicknote for Flint

Instant floating scratchpad for capturing thoughts, web snippets, and ideas without leaving your current note.

## 1. Installation
---

Install directly within Flint from the **Community Extensions Marketplace** or place into your Hearth's `.flint/extensions/quicknote/` folder.

## 2. Building Locally
---

```bash
npm install
npm run build
```
